Flood Exposure in Kaduna North LGA

Spatial Question

Which settlements in Kaduna North Local Government Area are most exposed to flood hazards?

Study Area

Kaduna North Local Government Area, Kaduna State, Nigeria.

Datasets

Dataset	Source
Kaduna North LGA Boundary	GRID3 — https://grid3.org/geospatial-data-nigeria
Flood Hazard Data	World Bank — https://datacatalog.worldbank.org/search/dataset/0067118/flood-hazard-100-year-return-period
Settlement Data	OpenStreetMap — https://www.openstreetmap.org/
Population Data	WorldPop — https://hub.worldpop.org/

Project Aim

This project aims to identify settlements within Kaduna North Local Government Area that are exposed to flood hazards by analysing flood hazard, settlement and population data.

Expected Outcome

The analysis will identify and map settlements that fall within or are close to areas exposed to flood hazards.
